# Цветочная история для Сайрины

В папке — интерактивная открытка с тремя вопросами, признанием, плавным появлением фотографии, букетом из 31 розы «Джумилия» и необязательным приглашением на кофе.

## Открыть открытку

Файлы style.css, main.js и IMG_2455.JPG должны лежать рядом с index.html. Финальная 3D-сцена использует Three.js r186 с официального CDN, поэтому для неё нужен интернет и локальный HTTP-сервер. Запустите в этой папке:

    python -m http.server 8000

Затем откройте http://localhost:8000/ в браузере. Остановить сервер можно сочетанием Ctrl+C в окне терминала.

## Создать QR-код-сердце

Для QR понадобится публичный веб-адрес страницы. Пока страница лежит только на компьютере, QR с телефона её не откроет. Фото никуда не загружается автоматически.

Установите библиотеку:

    python -m pip install -r requirements.txt

Затем создайте QR:

    python generate_heart_qr.py https://публичная-ссылка-на-страницу

Скрипт создаст прозрачный PNG, где QR обрезан по силуэту сердца. Он сохраняет три угловых маркера для наведения камерой и использует высокий уровень коррекции ошибок. После размещения сайта проверьте сканирование на телефоне, прежде чем печатать QR для букета.
